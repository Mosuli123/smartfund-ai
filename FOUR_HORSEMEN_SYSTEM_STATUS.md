## 🔧 DEBUGGING & TROUBLESHOOTING

### **Common Issues & Solutions**

#### **Issue 1: Backend Not Responding**
```bash
# Solution: Restart backend
cd backend
py main-enterprise.py
```

#### **Issue 2: Frontend Not Connecting to Backend**
```bash
# Solution: Check CORS settings and API URL
# Verify backend is running on port 8500
# Frontend should use: http://localhost:8500/api
```

#### **Issue 3: Port Already in Use**
```bash
# Solution: Change ports in configuration
# Backend: Edit main-enterprise.py (line with port=8500)
# Frontend: Edit package.json start script
```

#### **Issue 4: Dependencies Missing**
```bash
# Backend Dependencies:
pip install fastapi uvicorn reportlab

# Frontend Dependencies:
npm install
```

### **System Logs Location**
- **Backend Logs**: Console output (uvicorn logs)
- **Frontend Logs**: Browser console (F12)
- **Error Logs**: Check terminal where services are running
